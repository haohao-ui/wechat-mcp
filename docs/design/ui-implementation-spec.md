# 界面实现规格（对齐 11-14 效果图）

本文件是给实现 agent 的施工图。效果图在 `docs/design/current-pages-v1/*.png` 与 `docs/design/planned-pages-v1/*.png`。
可读图就用 `read_image` 直接看；读不了就严格按本文件。

## 0. 总则

- 目标：**浅色、留白、卡片化**的原生工作台。当前实现是跟随系统深色的扁平布局，属于偏差。
- 强制浅色：`main.swift` 里 `NSApp.appearance = NSAppearance(named: .aqua)`，页面不再依赖 `windowBackgroundColor` 的深色分支。
- 只改视觉表现，不改任何业务行为、接口、数据结构、L10n key 语义。
- 所有用户可见文案必须走 `L10n`（五语）；新增文案要同时补 zh/en/fr/it/pl 并加 `L10nKey` case。
- 单位：pt。间距只用 4/8/12/16/24/32。

## 1. 颜色 token（扩到 `Theme.Colors`）

| 窗口/内容区背景 | `#F2F3F5` |
| 卡片/表格背景 | `#FFFFFF` |
| 分隔线/卡片描边 | `#E3E5E8` |
| 主文字 | `#1F2329` |
| 次要文字 | `#646A73` |
| 主按钮（填充绿） | `#1E7A4D`，hover `#176540`，文字 `#FFFFFF` |
| 品牌浅绿（选中/标签底） | `#E6F4EC` |
| 品牌绿文字 | `#127954` |
| 侧栏背景 | `#F2F3F5`（与内容区同色，靠右侧 1px 描边区分） |

| 错误文字/底 | `#B73A3E` / `#FCE9EA` |

## 2. 字体与尺寸

- 页标题：28pt semibold（左侧，与顶部操作按钮同一行）
- 区块标题（卡片内）：17pt semibold
- 正文：13pt；次要说明 12pt；表格正文 13pt
- 指标数字：34pt bold，等宽数字（`NSFont.monospacedDigitSystemFont`），黄色/绿色/橙色按语义
- 卡片圆角 12；按钮圆角 8；表格行高 40；控件高 32（主按钮 36）
- 卡片内边距 20–24；卡片间距 20；页面外边距 24

## 3. 通用骨架（每个页面都一样）

```
页标题（28 semibold）        [次要按钮] [主要按钮]   ← 右对齐，右端外边距 24
──────────────────────────────────────────────
卡片 1（白底 / 12 圆角 / 1px #E3E5E8 描边 / 内边距 20）
卡片 2 …
```

- 页面根视图背景 `#F2F3F5`，不要渐变、不要阴影（浮层除外）。
- 主按钮：绿底白字、36 高、圆角 8；次要按钮：白底、1px `#D0D3D6` 描边、13pt 深色字。
- 表格：无斑马纹；表头 12pt 次要色、下方 1px 分隔；选中行底色 `#E6F4EC`。

## 4. 侧栏（`Shell.swift`）

- 宽 220pt，背景 `#F2F3F5`，右侧 1px `#E3E5E8`。
- 每项：图标（SF Symbols，16pt）+ 文字（13pt），高 40，左右内边距 12，项间距 2。
- 选中项：`#E6F4EC` 圆角 8 底 + 深绿文字；图标用同名 filled 变体。
- 导航顺序（已定，不要改）：总览 / 会话 / 联系人 / 客服角色 / 模型 / MCP 接入 / 设置 / 日志 / 应用更新。
- 「组件与配色」**不注册**进侧栏（设计规范交付物，只给开发看）。

## 5. 总览页（`OverviewPage.swift`，参照 `current-pages-v1/01-overview.png`）

1. 标题行：`总览` + 右侧两个次要按钮（重新检查 / 暂停自动回复，带图标）。
2. 三张并排指标卡（等宽，间距 20）：`今日回复` 大字（无数据时 `—`）、`监听会话`（绿字）、`待人工`（橙字）。卡片标题 13pt 次要色在上，数字在下。
3. `系统检查与诊断` 卡片：标题 17pt semibold；内部每行 = 状态圆点 + 名称（13pt 中黑）+ 状态文字 + 建议（12pt 次要色，可换行）+ 右侧次要按钮。
   行与行之间 1px 分隔线，行内边距 14。
4. 底部一行 12pt 次要色说明（如缺数据来源时如实写"暂无统计"）。

## 6. 会话页（`SessionsPage.swift`，参照 `current-pages-v1/02-sessions.png`）

**以效果图为准：单张全宽卡片「会话监听列表」，三列，不新增搜索/筛选/详情/摘要/时间。**

- 卡片标题：`会话监听列表`（17 semibold）。
- 表头三列：`会话` / `状态` / `操作`，12pt 次要色，下方 1px 分隔线，表头行底色 `#F5F6F8`。
- 行（行高 44，行间 1px 分隔线）：
  - 会话：显示名 13pt 深色；
  - 状态：`ThemeStatusTag` 胶囊——正常态绿底绿字（如"监听中"），需处理态橙底橙字（"已转人工：…" / "已暂停：…"），文字与数据里的 reason/code 对应；
  - 操作：只有需要人工介入的行才显示主按钮 `恢复自动回复`（`ThemePrimaryButton`，绿底白字）。
- 卡片底部保留空状态示意区（浅灰 #F5F6F8、圆角 8、居中 13pt 次要色"暂无活跃会话"），无数据时显示。
- 现有「轮次追溯」等内容放在本卡片下方，保持功能不变。
- **不新增**搜索框、分段筛选、左右分栏详情、摘要、时间列；这些属于后续 P1 新能力，效果图和设计清单都明确排除。

## 7. 联系人页（`ContactsPage.swift`，参照 `current-pages-v1/03-contacts.png`）

- 标题行：`联系人` + 主按钮 `初始化通讯录`、`立即同步`，次要按钮 `刷新`，右侧同步状态文案（成功显示绿色对勾 + `上次同步已完成`）。
- 待确认提示条：警告色横幅（`ThemeStatusBanner`）。
- 分段标签：`联系人(N) 企业微信(N) 群聊(N) 公众号(N) 已忽略(N)`，选中项绿底白字、未选中白底。
- 表格列：名字/备注、微信号、消息数、处理方式（复选框 `自动回复` + `忽略` 次要按钮）。
- 右侧详情卡（宽 300）：标题 `联系人详情`、名字 20pt semibold、字段行（微信号/备注名/地区/添加时间/来源/企业实名/标签/处理方式），底部主按钮。
- **本次新增（需求）**：预置/未同步行要标出来源，同步失败要给人话原因（见任务说明）。

## 8. MCP 页（`McpPage.swift`，参照 `current-pages-v1/04-mcp.png`）

- 顶部：模式选择（内置大脑/外部大脑）用卡片内单行 + 说明；连接状态用状态标签。
- 分组卡片：`连接` / `超时策略` / `开发者工具`；字段旁标注单位与范围；原始参数名、错误码、socket 路径放进可复制的技术详情区。

## 9. 设置页（`SettingsPage.swift`，参照 `current-pages-v1/05-settings.png`）

- 分组卡片：`系统权限` / `运行规则` / `界面语言` / `账号` / `应用与更新`。
- 每组内字段两列对齐（标签左、控件右，标签列宽 180）；说明文字 12pt 次要色在控件下方。

## 10. 日志页（`LogsPage.swift`，参照 `current-pages-v1/06-logs.png`）

- 顶部：标题 + 级别筛选（分段）+ 搜索 + 复制/清屏次要按钮。
- 日志区白卡片、等宽 12pt、行高 22，级别用彩色标签。

## 11. 客服角色 / 模型 / 应用更新

参照 `planned-pages-v1/07-brain.png`、`08-app-update-v2-simple.png` 与现有实现：同样套用上面的卡片骨架与 token，不改逻辑与文案。

## 12. 验收（每个页面都要做）

1. `swiftc -O -target x86_64-apple-macos12 native/bootstrap/*.swift native/eyes/Screens.swift -o /tmp/host-ui` 必须 0 error。
2. `cargo test --locked --test swift_host --test swift_brain_ui --test swift_update_ui --test swift_contacts --test swift_session_handoff` 全绿（含 t4 零写死中文约束）。
3. 交付说明里写清：改了哪些文件、每页对照效果图改了什么、跑过的命令与结果、还有哪些视觉细节没把握。
