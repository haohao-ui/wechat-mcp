# 生产更新：原生界面实际下载

本阶段接通检查后的真实下载，未启用安装、延期或恢复。完整部署验收尚未完成，记录v2格式仍等待Tech Lead确认。

## 修改

- 更新器status兼容增加capabilities schema 1，明确报告download/prepare和仍不支持的install/rollback/recover。下载要求配置有效、私有state、可信公钥可读及原只读启动守卫允许；没有该能力字段的旧更新器不会被界面视为支持下载。
- 检查结果增加签名清单摘要。Swift将下载回执与检查时的release_id、sequence、manifest摘要及规范UUID逐项匹配；源变化或异常回执不显示当前候选下载成功。
- 界面从核心程序同目录定位更新器，拒绝软链、错误owner、非普通可执行文件及外部可写目录。只有清单验签通过、实际更新器声明支持、状态可用且没有其它页面操作时才启用下载。
- 真实下载在后台执行。重复点击不会重复发起；成功显示“已下载”和“尚未安装”，组件验证和本机签名仍明确待完成。安装/延期保持禁用；下载不修改业务暂停状态或安装记录。
- 本页命令执行改为有输出上限和时限的管道读取，超时后终止本次子进程并必要时强制结束，不因未关闭的管道无限等待。失败和超时不会当作成功回执。
- 下载缓存增加独占锁、最多8个候选、总量1 GiB的硬限制。配额和锁冲突均拒绝新下载，不擅自删除未知文件或业务数据；单包原大小/验签/hash约束保留。
